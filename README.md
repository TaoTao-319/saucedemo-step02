# Sauce Demo 手工测试项目

## 项目说明

本项目用于记录软件测试学习第二周的手工测试实践。测试对象为 Sauce Demo，重点练习等价类划分、边界值分析、判定表和状态转换四种测试设计方法。

本项目的目标不是对 Sauce Demo 进行大规模测试，而是完整记录一次从测试分析、用例设计、执行、缺陷记录到测试总结的基本流程。

## 测试对象

- 测试网站：https://www.saucedemo.com/
- 测试范围：登录、商品浏览、购物车、结算信息校验、订单提交
- 测试类型：功能测试、正向测试、负向测试、基础状态转换测试
- 测试方式：手工测试

## 测试账号

| 账号 | 用途 |
|---|---|
| `standard_user` | 正常功能测试 |
| `locked_out_user` | 锁定账号异常场景 |
| `secret_sauce` | 通用密码 |

## 测试设计方法

1. 等价类划分：区分有效输入和无效输入。
2. 边界值分析：关注空值、最小输入、最大输入和临界输入。
3. 判定表：验证多个条件组合对结果的影响。
4. 状态转换：验证未登录、已登录、购物车有商品、结算和订单完成之间的状态变化。

## 测试结论

本次测试覆盖了 Sauce Demo 的核心登录和购物流程。主要正向流程可以完成，但测试过程中记录了 3 个需要进一步确认和跟踪的问题。对于学习目的，本项目已经完整覆盖了测试用例设计、执行记录、缺陷报告和测试总结的基本流程。

## 学习收获

- 能够根据功能分析有效和无效测试数据。
- 能够使用边界值补充异常场景。
- 能够使用判定表分析登录条件组合。
- 能够使用状态转换描述购物流程。
- 能够独立整理一份可展示的手工测试项目。
